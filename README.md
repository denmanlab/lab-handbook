## Provenance

Every page carries an HTML comment naming its original OSF node, wiki page, URL and
last-edited date. Four redactions were applied when publishing to this public
repository: the lab's internal eLabFTW address was replaced with its public hostname,
two internal IP references were replaced with the `denmanlab` hostname, and the URL of
the private colony spreadsheet was removed. A complete unredacted archive of the OSF
project is held offline.
